# Topological Data Analysis of NFL Defensive Formations
This repository supports the research paper: "Topological Data Analysis of NFL Defensive Formations: Does Persistent Homology Predict Coverage Breakdowns Beyond Standard Geometric Baselines?"

Manuscript Preprint: https://doi.org/10.20944/preprints202607.1646.v1

## Data Source
This research uses the publicly available NFL Big Data Bowl 2021 dataset. 
Data can be accessed here: https://www.kaggle.com/c/nfl-big-data-bowl-2021/data

## Code
The analysis code (logistic regression, Vietoris-Rips filtration, AUC evaluation) is included in this repository to ensure full reproducibility of the results.
